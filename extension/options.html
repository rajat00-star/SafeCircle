SafeCircle Guardian Shield settings

Text and links you choose to check are sent to this server for analysis. They are not stored unless you enabled history on that server's website.

Link guard (optional, off by default)

When on, a link you click that leads to another website is checked first. If it shows warning signs you see a warning page with a clear "Go back" option, and you can still choose to continue. Only the clicked link's address is sent to your server; page content, forms, passwords and browsing history are never read or collected. Turning it on asks Chrome for access to websites, which this needs to see link clicks. If the server is offline, links open normally and the toolbar shows "?".
